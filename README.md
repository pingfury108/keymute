# KeyMute（键默）

只锁**本地物理键盘**的 macOS 菜单栏小工具：触控板、屏幕、远程注入的按键一切照常。

- 擦键盘、防误触
- 远程接管（UU 远程等）时把本地键盘彻底锁死，远程输入不受影响

## 特性

- 一键锁定，字母键 / 修饰键 / 功能键 / 音量亮度键全部失效
- 触控板与鼠标完全不受影响，随时能点菜单栏解锁
- 远程注入的按键照常生效（只吞硬件来源的输入）
- 锁定期间屏幕不黑、系统不休眠，远程不断线
- 自动解锁（5 / 10 / 30 分钟或永不，默认 10 分钟）
- 菜单栏显示锁定图标与倒计时，菜单首行显示已锁时长
- 全局快捷键 ⇧⌘K 锁定
- 可设为开机自启
- 进程退出或崩溃即恢复，无需额外操作

## 安装

```bash
make install
open -a KeyMute
```

首次运行到「系统设置 → 隐私与安全性 → 辅助功能」勾选 KeyMute。之后可在菜单里打开
「开机自启」，就不用再手动启动了。

## 使用

菜单栏图标：⌨️ 空闲 / 🔒 锁定中 / ⚠️ 缺少辅助功能权限。

```
键盘已锁定 · 00:42 · 10:00 后自动解锁
────────────────────────
✓ 锁定键盘                              ⇧⌘K
  自动解锁  ▸  5 / 10 / 30 分钟 / 永不
✓ 允许远程输入（UU 远程）
✓ 全局快捷键 ⇧⌘K
✓ 开机自启
────────────────────────
  诊断日志…
────────────────────────
关于 KeyMute
退出
```

锁定期间**故意不提供键盘解锁**——否则抹布一压就解了。解锁只靠鼠标/触控板，或等自动解锁；
菜单里的「退出」同样可用。

## 说明

- 不做安全用途：登录窗口、锁屏、Secure Input 输入框拦不住
- 其他工具注入的按键会被放行，这是"只放行非硬件来源"的必然结果
- 触控板锁定暂不支持（与"必须能点菜单栏"冲突）

## 开发

```bash
make          # 构建 build/KeyMute.app
make restart  # 重启（改代码/换图标后）
make icon     # 重新生成图标
```
